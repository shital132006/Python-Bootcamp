# Day 19 - Positive & Negative Indexing

## Topics Covered
- Positive Indexing
- Negative Indexing
- Accessing individual characters

## Example

String = "Shital"

Positive Index

S -> 0
h -> 1
i -> 2
t -> 3
a -> 4
l -> 5

Negative Index

S -> -6
h -> -5
i -> -4
t -> -3
a -> -2
l -> -1

## What I Learned

- Positive indexing starts from 0.
- Negative indexing starts from -1 (last character).
- Negative indexing is useful when we want the last character without knowing the string length.
