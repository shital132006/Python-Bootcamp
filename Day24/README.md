# Day 24 - List Modification

## 📚 Topics Covered

- Modifying List Elements
- Updating Values
- Mutable Lists

---

## 📝 Definition

Lists in Python are **mutable**, which means we can change, update, or modify their elements after the list has been created.

---

## 💻 Programs

### Program 1 - Modify a List Element

```python
colors = ["Red", "Blue", "Green"]

colors[1] = "Yellow"

print(colors)
```

Output

```
['Red', 'Yellow', 'Green']
```

---

### Program 2 - Update City Name

```python
cities = ["Mumbai", "Pune", "Delhi"]

cities[2] = "Chennai"

print(cities)
```

Output

```
['Mumbai', 'Pune', 'Chennai']
```

---

### Program 3 - Update Marks

```python
marks = [75, 80, 90]

marks[0] = 95

print(marks)
```

Output

```
[95, 80, 90]
```

---

## 🎯 What I Learned

- Lists are mutable.
- We can modify values using indexes.
- The original list is updated after modification.
