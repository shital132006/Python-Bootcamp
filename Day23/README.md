## 📝 Definition

A list is an ordered, mutable collection in Python that can store multiple values in a single variable.

---

## 💻 Programs

### Program 1

```python
cities = ["Mumbai", "Pune", "Delhi"]

print(cities)
```

Output

```
['Mumbai', 'Pune', 'Delhi']
```

---

### Program 2

```python
cities = ["Mumbai", "Pune", "Delhi"]

print(cities[0])
print(cities[1])
print(cities[2])
```

Output

```
Mumbai
Pune
Delhi
```

---

### Program 3

```python
numbers = [10, 20, 30, 40]

print(len(numbers))
```

Output

```
4
```

---

## 🎯 What I Learned

- Lists store multiple values.
- Lists are mutable.
- Lists use indexing starting from 0.
- We can access elements using indexes.
