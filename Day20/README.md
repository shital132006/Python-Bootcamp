# Day 20 - String Slicing

## Topics Covered

- String Slicing
- Start Index
- End Index
- End Index is Excluded

## Example

word = "DataAnalysis"

word[0:4]  → Data

word[4:12] → Analysis

word[4:8]  → Anal

word[8:12] → ysis

## What I Learned

- String slicing extracts a group of characters.
- The starting index is included.
- The ending index is excluded.
- Slicing is useful when working with names, IDs, and text data.
