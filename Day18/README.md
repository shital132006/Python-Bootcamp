# Day 18 - String Indexing Basics

## Topics Covered
- What is a String?
- Strings are enclosed in quotes
- String Indexing
- Index starts from 0

## Example

name = "Shital"

S = 0
h = 1
i = 2
t = 3
a = 4
l = 5

## What I Learned
- A string is a sequence of characters enclosed in quotes.
- Python starts indexing from 0.
- We can access individual characters using square brackets [].
